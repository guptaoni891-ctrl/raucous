# Contributing

Thanks for improving VinylPulse.

1. Fork the repository and create a focused branch.
2. Install development dependencies with `python -m pip install -e ".[dev]"`.
3. Add or update tests for behavioural changes.
4. Run `make check` before opening a pull request.
5. Keep pull requests small and explain the user-facing impact.

Do not commit OAuth tokens, `.env` files, local configuration, recordings or
copyrighted media.
